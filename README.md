# udemy-ai-security-basic

Udemy講座「AI時代のWebセキュリティ入門」（仮）の教材リポジトリです。
2人のユーザーがメモを管理する小さなWebアプリ（`app/`）に、学習用の脆弱性をわざと仕込んでいます。

> **警告**
>
> - このアプリは学習のために、**わざと脆弱に作っています**。
> - **本番環境では絶対に使わないでください。** インターネットに公開するサーバーにも置かないでください。
> - 攻撃の練習は、**自分のPCの中（ローカル環境）で動かしたこのアプリだけ**で行ってください。
> - 他人のサイトやサービスに同じことを試すのは、不正アクセス禁止法などの**法律違反になりえます**。

> **このリポジトリについての注意**
>
> 講座（章3「git履歴に秘密が残る」）の教材として、`app/.env` や `app/public/app.js` のAPIキーを
> **わざとgitにコミット**しています。キーはすべて架空の値です。
> 普通のプロジェクトでは、秘密情報をgitに入れるのは絶対にやめましょう。

## 起動方法

Docker が必要です。

```bash
cd app
docker compose up
```

起動したら、ブラウザで http://localhost:4100/login.html を開きます。

Docker を使わない場合や、攻撃の確認コマンド例は [app/README.md](app/README.md) を見てください。
